## Activity 13: Print Numbers from 1 to N using a For Loop  

**Objective:**  
Learn how to use a for loop to print a sequence of numbers based on user input.  

Instructions:  
1. Create a Java class named NumberPrinter.  
2. In the main method:  
Ask the user to input a min number (positive integer).  
Ask the user to input a max number (positive integer).  
Use a for loop to print all numbers from (inclusive).  
Each number should appear on a new line.  
-----------------------------------------------  
  Expected Sample Output:  
-----------------------------------------------  
Enter min number: 1  
Enter max number: 5  

1  
2  
3  
4  
5
