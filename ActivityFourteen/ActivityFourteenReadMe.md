## Activity 14: Print Numbers from N to 1 using a For Loop (Descending)  

**Objective:**  
Practice using a for loop to print numbers , from N.  


**Instructions:**  
1. Create a Java class named DescendingPrinter.  
2. In the main method:  
Ask the user to enter max number .  
Ask the user to enter min number .  
Use a for loop to print numbers starting from maxNumber to minNumber.  
Each number should appear on a new line.  
  Challenge (Bonus Points):  
Add a message like: Loop complete! after the list ends.  

----------------------------------------------  
  Expected Sample Output:  
----------------------------------------------  
Enter max number: 5  
Enter min number: 1  

5  
4  
3  
2  
1
