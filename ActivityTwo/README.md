### Activity 2

**Objective:**
Learn how to use variables and the Scanner class to accept input from the user and display personalized output.  


**Instructions:**
1. Create a new Java class file named UserIntroduction.java.
2. Complete the TODOs to:

Accept name, age, and favorite hobby  <br>
Store them in variables  <br>
Print a short introduction using the input  <br>
Sample output:  <br>
What is your name?   <br>
user input: Alex  <br>
How old are you?  <br>
user input: 18  <br>
What is your favorite hobby?  <br>
user input: Drawing  <br>

Nice to meet you, Alex!  
You are 18 years old and love Drawing.
